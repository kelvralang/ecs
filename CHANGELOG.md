# Changelog

## 0.2.0 - 2026-09-04

- Rename the package's language sources, manifests, imports, automation, and
  documentation from Mog to Kelvra, requiring Kelvra 0.2.0 or newer.

## 0.1.0 - 2026-08-01

- Extract the native-performance C++ ECS from the Kelvra language runtime into an
  independently built external package repository.
- Add entity generations, sparse-set component storage, invalidating queries,
  fixed-layout schemas, byte codecs, C/C++ tests, Kelvra integration tests, and
  benchmarks.
